# Plotline Timnath

A resident survey prototype for downtown Timnath, Colorado. Residents say what they want in available Main Street buildings, rate a test idea, and see public, aggregated results.

- `index.html` is the whole site (served by GitHub Pages).
- Answers are stored in a Google Sheet through a Google Apps Script web app (`Code.gs`). Set its `/exec` URL as `API_URL` in `index.html`.

Listing details come from public commercial listing sites (November 2026) and may be out of date. Concept images are illustrations only.
